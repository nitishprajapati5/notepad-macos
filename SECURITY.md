# Security Policy

The Notepad for macOS team takes the security of our software and users seriously. We appreciate any efforts to responsibly disclose security vulnerabilities.

---

## Supported Versions

We provide security updates and bug fixes for the current major release version:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a potential vulnerability in Notepad for macOS:

1. **GitHub Security Advisory (Preferred)**:
   - Navigate to the repository's **Security** tab.
   - Click **Report a vulnerability** to open a private advisory draft.
2. **Direct Contact**:
   - Alternatively, contact project maintainers directly via email or private channels.

### Information to Include

When submitting a report, please include:
- A clear description of the vulnerability.
- Steps or a minimal proof-of-concept (PoC) demonstrating how to reproduce the issue.
- The affected version(s) of Notepad for macOS.
- Your macOS version and architecture (Apple Silicon `arm64` or Intel `x86_64`).
- Any potential remediations or mitigations you have identified.

---

## Response Timeline

- **Initial Response**: We aim to acknowledge receipt of your report within 48 hours.
- **Triage & Assessment**: We will assess the severity and impact within 5 business days.
- **Fix & Disclosure**: Once a fix is verified, a patched release will be published and an advisory will be publicly credited to the reporter (unless you prefer anonymity).

Thank you for helping keep our software and users safe!
